At Tata Consultancy Services, Shaahil worked on a global investment bank's real-time financial data quality and regulatory compliance platform, which included a data quality (DQ) dashboard. A platform of this kind monitors whether data is complete, accurate and on time, applies validation rules, reports and analyses data quality issues, and supports regulatory data aggregation and risk reporting.

The architecture was simple: an Angular.js front end, Spring Boot middleware and an Oracle SQL database. Data files arrived through RabbitMQ from locations across the world. The platform processed the data and helped fix any issues, so that other teams could show correct details. Bank employees used the dashboard to see liabilities, collateral and other data such as risks. Many teams depended on the platform, so Shaahil built multiple REST APIs to keep the data secure and easy to access.
