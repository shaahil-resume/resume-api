At Tata Consultancy Services, Shaahil created a reconciliation report that found inconsistencies in the data the application processes. It reduced manual intervention and cut the time to complete the work from 5 days to 2, a result measured by the people using it. He built it with Java and Selenium for the testers. The application's final processed file is passed to the automation, which verifies each record against the user interface and against another file and performs calculations to confirm that all the data is consistent. Testers could check the data faster instead of checking each record by hand.
