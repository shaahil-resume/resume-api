Before Shaahil introduced GitHub Actions, the application was deployed to traditional WebLogic servers. Deployments needed several people to come in early to do the deployment, for other teams as well as his own. He introduced GitHub Actions CI/CD to remove that manual work. Every pull request now builds automatically and deploys to a lower environment. The pipeline sends an automatic email when there are issues, so the team is alerted, and after testing a change is promoted through the later release environments. The change cut deployment time by 90% and manual intervention by 50%.
