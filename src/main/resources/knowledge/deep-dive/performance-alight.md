Users noticed slow screen load times and operations that took a long time to process. There were several causes. Some Hibernate and JPA queries were inefficient, using N+1-style patterns, where one request triggers many small queries, and unnecessary multi-table joins, including tables that had nothing to do with the data being asked for. Shaahil optimised these queries so they fetched only the data needed from the correct tables. After the fixes, screen load times and processing times improved significantly, which improved speed and reliability for high-volume benefits data.
